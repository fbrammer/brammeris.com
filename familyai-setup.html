Let's get your AI assistant set up

This takes about 10 minutes. No technical background needed — just follow along and copy/paste exactly what's shown. Once you get to the last step, your new assistant takes over and walks you through everything else itself.

Which computer are you on?

1Create a free GitHub account

Go to github.com and sign up — just a username, email, and password, no payment info required. Verify your email if GitHub asks you to.

You won't need to actually use this site yourself. It's just a one-time account your assistant uses behind the scenes to install and update itself.

2Open a terminal

Press Cmd + Space, type Terminal, press Enter.

Click the Start menu, type PowerShell, press Enter.

3Tell it who you are

Enter your name and the email you used for your new GitHub account — the commands below will fill themselves in as you type. Then copy the result, paste it into the window you just opened, and press Enter.

git config --global user.name "Your Name"
git config --global user.email "your-github-email@example.com"

Check it worked: paste this and confirm your name/email print back:

git config --global user.name
git config --global user.email

4Install your assistant

Paste this and press Enter:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

Then close and reopen Terminal completely (not just a new tab) so it picks up the new command.

If it asks for your password to install with elevated permissions ("sudo"), stop and don't enter it — the normal installer doesn't need that. Something's wrong; make a note and come back to it.

Paste this and press Enter:

iex (irm https://hermes-agent.nousresearch.com/install.ps1)
If PowerShell blocks this with an "execution policy" error, close and reopen PowerShell and try again. If it still fails, make a note and come back to it rather than changing security settings.

Then close and reopen PowerShell completely so it picks up the new command.

5Check it's healthy

In the same window, paste:

hermes doctor

It should report a healthy install with nothing missing. If it doesn't, don't continue — whatever it flags needs fixing first (it usually tells you exactly what to do).

6Meet your assistant

This is the last step you do on your own. Starting right now, you're handing off to your new AI assistant — everything from here is between the two of you: it'll finish setting itself up, you'll get to decide who it is and how it works, and you'll get to know each other with a few things to try together. You don't need to know anything technical from this point on — just follow along and talk to it like you would a person.

Paste this and press Enter:

hermes

Once it starts, paste this exact message and send it:

Please fetch and read this document: https://raw.githubusercontent.com/fbrammer/familyai-hermes-template/main/onboarding-wizard.md — it's an onboarding wizard for setting you up. I've already completed sections 0-2 myself (GitHub account, git identity, and installing you). Please start at section 3 and walk me through the rest, one step at a time, exactly as written.

From this point on, just follow along with whatever it asks.
